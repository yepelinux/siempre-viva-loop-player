# Andisei · Coros en loop

Reproductor web para practicar los coros de la escuela de comedia musical Andisei: elegís tu voz, un track del compilado o un tramo a medida, y lo repetís en loop hasta que sale.

Es una página estática (`index.html` + `audio/`). Los cortes de los tracks salen de los silencios del compilado y son los mismos para las 4 voces.

Para correrlo local: `node server.mjs` → http://127.0.0.1:8095 (sirve el audio con Range para poder adelantar).
